- 14:28:07，实际 POST `/api/mandatory/buyback`，请求 `{"applicationNos":["JK026072714343944"]}`，请求 ID `wh-202611190001-array-D-1`。
- 预期：JK-D 已配置取消回购，应拒绝且不新增回购单。

- 调用前该申请单回购明细为空；调用后生成 **FHGA26112014280800011**（id=6787、statement_type=2000、create_time=2026-11-20 14:28:09），关联 **25 条回购明细**。该单 **12 期还款计划从 bill_status=100 变为 600（待回购）**。
- 对照：同一申请单在 14:13 使用 `applicationNo` 单值参数两次均被项目排除拦截。

- 已保留测试现场，不重复扩大该失败路径。未支付/审批这笔回购单，未执行 SQL 回滚；当前测试资源的 DB 工具只允许只读查询。
