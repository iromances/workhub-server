# 业务线访问地址支持登录凭据配置与 AI 读取

## 背景

业务线"访问地址与网关"（表 `pm_business_line_access_config`）目前只存环境/类型/名称/URL/网关前缀。需求：每条访问地址可配置**登录账号 + 登录密码**两个输入框，密码加密存储，AI 经 MCP 工具读取后可在浏览器自动测试时输入登录。

关键先例（复用，不新造）：
- 加密：`McpCryptoService`（AES-GCM，`workhub.mcp.master-key`，workhub-service），`mcp_resource_config.password_encrypted` 模式——存储加密、管理端响应只给 `passwordConfigured` 布尔、保存留空表示保留原值。
- MCP 输出：`McpRuntimeService.accessEndpointSummary` 被 `get_business_line_context` / `get_business_line_test_context` / `get_requirement_test_context` 三个工具共用，输出为结构化 map，不经过查询/日志的脱敏管线，可承载明文凭据。

新建 `docs/业务线/BL000012-工作台/需求迭代/REQ-{UUIDv4}-业务线访问地址登录凭据与AI读取/proposal.md`、`design.md`、`tasks.md`（沿用 REQ-95321398 目录的三份规格结构）。业务线编码 BL000012-工作台。

## 二、后端 workhub-server

1. **Flyway 迁移** `workhub-bootstrap/src/main/resources/db/schema/mysql/V20261110_HHMMSS__business_line_access_login_credential.sql`：
   `pm_business_line_access_config` 增加 `login_username` VARCHAR(128) NULL、`login_password_encrypted` TEXT NULL（命名对齐 `mcp_resource_config.password_encrypted`）。
2. **模型** workhub-model/project：
   - `BusinessLineAccessConfigEntity`：+ loginUsername、loginPasswordEncrypted
   - `BusinessLineAccessConfigRequest`：+ loginUsername、loginPassword
   - `BusinessLineAccessConfigResponse`：+ loginUsername、loginPasswordConfigured（Boolean；不回显明文）
3. **DAO** `BusinessLineAccessConfigMapper`：SELECT/INSERT 增加两列。
4. **ProjectService**（workhub-service/project/ProjectService.java）：
   - 构造器注入 `McpCryptoService`（现有 5 参构造 +1，同步更新测试构造点）。
   - `normalizeAccessConfigs`：loginUsername trim、≤128；loginPassword 非空则 `encrypt` 后落 `loginPasswordEncrypted`；为空时按身份键（环境+类型+名称小写，与唯一性校验同键）从删除前的存量行复用加密值（`replaceAccessConfigs` 删前先查现表建映射）。
   - `toAccessConfigResponse`：输出 loginUsername + loginPasswordConfigured（加密列非空即 true）。
5. **McpRuntimeService**：@Autowired 主构造器追加 `McpCryptoService`（既有 telescoping 构造器委托传 null，17 处测试调用点不用改）；`accessEndpointSummary` 在已配置且 cryptoService 可用时输出 `loginUsername`、`loginPassword`（解密明文，供 AI 浏览器自动登录）。
6. **测试**：
   - `ProjectServiceBusinessLineAccessConfigTest`：新增——带密码保存后落库为 `mcp:v1:` 密文；编辑密码留空保留原密文；响应含 loginUsername/loginPasswordConfigured、不含明文密码。
   - `McpRuntimeServiceTest`：新增——accessEndpoints 含解密后的账号与密码；未配置时不输出字段。
7. **文档**：`docs/mcp-server.md` 工具表与"安全边界"补充说明（访问地址登录凭据加密存储、经 MCP 令牌通道按需明文下发）；`docs/业务线/BL000012-工作台/现状.md`、`迭代日志.md` 按交付规则更新。

## 三、前端 workhub-web（兄弟仓库，当前分支直接改动）

1. `src/types/work-item.ts`：`ProjectGroupAccessConfig` + loginUsername、loginPasswordConfigured。
2. `src/api/project.ts`：`ProjectGroupSaveRequest.accessConfigs` 项类型改为 `Omit<ProjectGroupAccessConfig, 'id'|'createdAt'|'updatedAt'|'loginPasswordConfigured'> & { loginPassword?: string }`。
3. `src/views/project/ProjectListView.vue`：
