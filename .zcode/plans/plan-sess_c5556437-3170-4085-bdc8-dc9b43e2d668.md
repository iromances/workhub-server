# 数字员工（Agent）增加删除按钮

## Context

数字员工页 `/agents` 目前 Agent 本体只有创建/配置/启用/停用，不能删除；任务级删除已按 REQ-8985f2f0 于 2026-11-10 实现（`DELETE /api/agent-tasks/{id}`：物理删除、版本乐观锁、前置校验、同事务先写 DELETE 审计），用户现要求给数字员工本体也增加删除按钮。按仓库 SDD 流程：建档 → 起草三份规格 → 用户确认（本次计划批准即规格确认，沿用 REQ-8985f2f0"方案选定即确认"模式）→ 实施 → 交付记录。

**删除语义（镜像已确认的任务删除模型）**：物理级联删除 + 证据保全。存在过程数据（观测/候选变更/代码工作区/构建测试/发布计划/部署/复查/巡检分配/问题协作）即拒绝删除，错误信息说明类别与替代操作（停用）；审计行永远保留。

## 需求建档（实施第一步）

新需求 `REQ-3f9a1c7e-8d24-4b6a-9c15-7e2d84a05b31-数字员工删除`，目录 `docs/业务线/BL000012-工作台/需求迭代/REQ-3f9a1c7e-8d24-4b6a-9c15-7e2d84a05b31-数字员工删除/`，写 `proposal.md` / `design.md` / `tasks.md`（沿用 REQ-8985f2f0 格式：元信息表、Why/What/Done 验收表、确认记录）。

## 后端（workhub-server，分支 codex/development-20261102）

无 DDL（沿用现有表）。

1. **`workhub-dao/.../agent/AgentMapper.java`** — 新增：
   - `countUnfinishedRunsByAgent(agentId)`（与任务删除同一状态集：QUEUED/RUNNING/CANCELLING/WAITING_RESOURCE 拒绝，WAITING_INPUT 不阻拦）
   - `countEnabledSchedulesByAgent(agentId)`
   - `agentRemovalCounts(agentId)`：镜像 `taskRemovalCounts` 的 9 类过程数据，经 `pm_agent_run.agent_id` 关联 + 复用 `TaskRemovalCounts` record（hasProcessData/processCategories 直接复用）
   - `deleteEventsByAgent / deleteArtifactsByAgent / deleteRunsByAgent / deleteTasksByAgent`（按 agent_id）、`deleteAgentById(id, version)`（版本条件）
2. **`workhub-service/.../agent/AgentWorkbenchService.java`** — 新增 `@Transactional deleteAgent(id, expectedVersion, user)`，顺序镜像 `deleteTask`（AgentWorkbenchService.java:199）：
   `actor.require("agent:manage")` → `mapper.lockAgent` → `access.requireAgent`（归属校验）→ `requireVersion` → 依次拒绝：①Agent 未停用（"请先停用后再删除"）②存在启用中的周期任务（"请先暂停周期"）③未结束运行 ④过程数据（报类别，提示停用替代）→ 先 `audit("AGENT", id, "DELETE", {name, 删除计数})` → 级联删 产物/事件/运行/任务 → `checkChanged(deleteAgentById)`。
3. **`workhub-controller/.../agent/AgentController.java`** — 新增 `@DeleteMapping("/{id}")`，`@PreAuthorize("hasAuthority('agent:manage')")`，`@RequestParam long expectedVersion`（与任务删除一致）。

## 前端（workhub-web，分支 codex/development-20261103）

1. **`src/api/agent.ts`** — 新增 `deleteAgent(agent)`：`http.delete('/agents/{id}', { params: { expectedVersion: agent.version } })`（镜像 `deleteAgentTask`）。
2. **`src/views/agent/AgentWorkbenchView.vue`** — Agent 表格"操作"列（当前 任务/配置/停用，宽度 215→265）追加"删除"按钮（`v-if="canManage"`、`link type="danger"`）；`removeAgent`：`ElMessageBox.confirm` 二次确认（文案说明物理删除范围与四项前置条件，镜像 removeTask:121 风格）→ 调 API → 成功提示、刷新列表，若删除的是当前选中 Agent 则清空 `selected`（任务区随之隐藏）→ 失败 `ElMessage.error(errorText)`。
