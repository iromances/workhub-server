## 运行契约

实例环境确定仓库根与规范根，默认相对于源码根或实际 JAR。归档仓库支持用户显式路径、GitLab 工程标识和持久化检出。命名空间按段校验，根目录与读取授权分别管理。实时规范按任务读取。Windows 按 NTFS ACL 保护任务文件，POSIX 使用私有权限。两类 Git 和 AI 入口复用可信程序解析。只读分析保留原授权边界。

桌面能力与已有用户权限取交集；后端在打开服务之前判断开关，默认和 prod 关闭，dev 开启。图片原件继续由数据库管理，API 使用内存图片，CLI 按需在任务目录创建临时文件。JSch 接入已有共享连接生命周期，Windows 使用回环端口转发，沿用配置隔离和超时回收。主机公钥校验与 OpenSSH `accept-new` 一致（2026-11-28 调整，见 Tasks 同日章节）：未登记的公钥在首次连接时追加到运行账号的 `known_hosts` 并记入日志，已登记且一致的直接通过，发生变化的拒绝；追加失败时连接失败并明确报错。

## 交付及回退

保留既有接口、文档归属与数据库附件格式。回退部署恢复旧产物和保存的实例配置，保留归档、未提交材料及数据库。真实环境验收使用隔离库、服务账号和测试目标。
