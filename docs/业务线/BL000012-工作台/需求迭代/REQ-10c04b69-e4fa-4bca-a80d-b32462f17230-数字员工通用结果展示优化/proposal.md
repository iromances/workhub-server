## 背景与范围

当前历史列表占据首屏，正文与下载 HTML 均以 pre 显示原文。本期统一所有员工的报告阅读体验：

1. 安全排版标题、段落、列表、表格、引用、代码及链接；页面与导出同源。
2. 结论优先摘取明确摘要章节，缺失时标明报告摘录。指标从明确指标表、带数值的章节标题摘录，保留名称、单位和口径；不猜测业务健康、不将缺失记为零。运行概况单独展示。
3. 历史批次侧栏分页，右侧报告；首次优先当前页最近完成轮次，保留人工选择；窄屏上下布局。

不变更数据库、API、权限、修复/发布行为，不安装依赖。报告原文仍是持久事实来源，阅读辅助不改写业务数据。
