# Design：数字员工通用结果展示优化

编码 REQ-10c04b69-e4fa-4bca-a80d-b32462f17230；对应 Proposal v1；唯一目录为本目录，归属 BL000012-工作台。涉及 workhub-web 展示及 workhub-server 规格归档，分支与环境同 Proposal。

## 现状与设计

2026-11-19 核对本机源码：AgentRunPanel 用 pre 输出 resultText；AgentWorkbenchView 在详情上方展示运行表。AgentRunDetail 提供 run/events/artifacts，未提供统一业务 metrics。REPORT payload 保存 text。前端未安装 Markdown 依赖。

- agentReportPresentation 集中处理安全 Markdown、摘要、显式指标摘录、导出和共享样式。所有原始文本转义，生成标签受限，链接只允许 HTTP/HTTPS 和页内锚点；原始 HTML 作为文本，代码块不参与摘要与指标抽取。
- AgentReportView 展示本轮结论、报告指标、完整报告。指标不自动判定正常/异常，保留原文语义和统计上下文；最多六项，并明确摘录来源。缺失时提示未单列，不从任意数字猜测指标。
- 实际兼容细化：中文“一、章节：正文”可分节；带明确数量/未配置等状态的编号章节首句可原文摘录，长度不超过 180 字。无摘要的普通报告仅截取首段最多 360 字并加省略号，完整原文仍在下方；不删除标识符中的下划线。
- 产物数、行动次数、耗时单独放运行概况。在线与 HTML 导出使用同一内容和样式生成逻辑。
- 历史侧栏使用原生 button 和 aria-current；分页沿用现有 API。首次选择当前页最新完成轮次（不是全历史搜索），翻页进入该页记录，轮询不抢走人工选择；新建/重试显式选择新运行。
- 任务、批次切换或关闭使迟到响应失效；错误不继续展示过期详情。窄屏降为上下排列，报告无固定 500px 高度。

## 契约与非功能边界

无 API、数据库、依赖、配置变更。摘要和指标属于阅读辅助，不计算金额、不跨窗口合计、不改写结果/验收状态。保留现有权限与外部操作确认。渲染为常用 Markdown 子集，未知语法保留可读原文。

## 验证与回滚

用现有 npm run build；独立测试报告格式、安全、摘录口径及运行选择；本机浏览器只读核对叉车和其他员工、窄屏及分页。回退本次前端差异即可，无数据迁移。验证后更新前端架构/路线图及工作台现状和迭代日志。
