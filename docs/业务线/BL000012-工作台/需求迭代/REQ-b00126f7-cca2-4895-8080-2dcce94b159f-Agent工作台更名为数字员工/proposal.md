## 1. 背景

Agent 工作台（`/agents`，权限 `agent:view`）当前在导航菜单、路由标题与页面标题三处显示“Agent 工作台”。用户要求该名称改为“数字员工”。

## 2. 目标与范围

1. 用户可见的工作台名称统一显示“数字员工”：菜单项、路由 `meta.title`、页面 `<h2>` 标题三处。
2. 明确不做：
   - 页面内部实体称谓仍用“Agent”（如“创建 Agent”、Agent 列格、Agent 配置弹窗），API 路径 `/api/agents`、路由 `name: 'agent-workbench'`、权限 `agent:view`、目录 `src/views/agent/` 等代码标识不变；
   - 后端代码与数据库不改动（后端源码无“工作台”字样文案）；
   - 历史需求规格、迭代日志旧条目等历史记录保留原称，仅更新现行状态文档（现状.md、frontend-architecture.md 当前模块章节）。

约束：不安装依赖，不自行启动或部署应用。

## 3. 验收标准

| 编号 | 可观察的验收条件 | 核对方式 |
| --- | --- | --- |
| AC-01 | 左侧菜单 `/agents` 项显示“数字员工” | 代码核对与前端构建；页面联调待部署 |
| AC-02 | 进入 `/agents` 后浏览器标题/面包屑取路由标题“数字员工” | 代码核对与前端构建 |
| AC-03 | 页面主标题 `<h2>` 显示“数字员工”，页面其余功能与文案不变 | 代码核对与前端构建 |
| AC-04 | 现行文档（现状.md、frontend-architecture.md）以“数字员工”指称该模块并保留原称说明；历史文档不改动 | 文档核对 |

设计与任务见 [design.md](design.md)、[tasks.md](tasks.md)。
