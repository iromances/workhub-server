# Proposal：MCP服务器目录与文本文件受控读取

需求编码：REQ-da3c89c7-3acc-4a12-9140-b97359d2ea52；需求名称：MCP服务器目录与文本文件受控读取；版本 v1.0；日期 2026-11-03。

所属业务线：BL000012-工作台；涉及仓库：workhub-server（MCP、资源管理、持久化与测试）。唯一目录：`docs/业务线/BL000012-工作台/需求迭代/REQ-da3c89c7-3acc-4a12-9140-b97359d2ea52-MCP服务器目录与文本文件受控读取`。本地分支 `codex/development-20261102`，基线提交 `4412e13387f0eb9cb6294b65c67433f057155af2`；保留现有其他任务改动。

## 背景与范围

用户检查物流测试服务器 `/mnt/etc-server` 启动脚本时，现有 MCP 仅支持 systemctl/journalctl/日志读取，无法浏览目录和读取脚本。用户已在本会话确认固定只读操作与路径限制，并明确要求“开放给AI读取目录，文件，文件内容的能力，改下代码和mcp”。

本轮增加 `list_server_directory`、`read_server_file` 两个只读工具，以及资源级独立 `allowedFilePaths` 白名单。目录支持有上限的深度与条数；文件仅返回有行数、字节上限的 UTF-8 文本，内容脱敏。复用 SSH、超时和审计。空白名单关闭新能力，旧客户端省略字段保留已有授权，显式空数组撤销。不开通进程查询、写文件、执行用户脚本、任意 shell，不改前端，不安装软件，不在本轮部署或执行数据库迁移。

## 验收

| 编号 | 可观察条件 | 验证 |
| --- | --- | --- |
| AC-01 | HTTP 与独立 MCP 均提供两个工具，目录返回文件元数据，文件返回内容及截断标志 | 注册及执行测试 |
| AC-02 | 独立白名单由资源 API 保存、返回并进入 catalog；默认关闭，不扩大现有日志权限 | 单元测试 |
| AC-03 | 拒绝越界、软链接（含中间组件）、二进制、特殊文件、敏感密钥文件与命令注入；限深度、条数、行数、字节和耗时 | 无网络本地隔离验证 |
| AC-04 | 脱敏配置和脚本中的凭据；审计记录路径/操作，不记录文件内容 | 脱敏与审计测试 |
| AC-05 | 更新迁移与用法说明，明确开发完成与部署状态 | 文档及差异检查 |
