# Proposal：MCP 服务器目录与文本文件受控读取

需求编码：REQ-da3c89c7-3acc-4a12-9140-b97359d2ea52；版本 v2.0；日期 2026-11-03。所属业务线 BL000012-工作台；后端 workhub-server、前端 workhub-web 共用本唯一目录。

## v2 范围与确认

用户明确要求移除独立 allowedFilePaths，与页面“日志目录白名单”合并为“允许 AI 读取的白名单目录”；补充“其他目录需要用户明确授权”“目前全部默认配置 /mnt”。本轮按该明确授权实施，不自动发布或修改运行数据库。

复用已有 allowedLogPaths / allowed_log_paths_json 为唯一配置，保留接口字段以兼容现有页面。移除上一轮尚未发布的独立字段与建列迁移。服务器新建默认 /mnt，更新省略时保留已有值；显式 [] 关闭路径读取。迁移先只备份 SERVER 资源 id、key 与旧目录，再将全部服务器配置统一为 ["/mnt"]，不保留其他目录的隐含授权。

页面列表、表单、默认值、占位和说明同步修改。白名单之外的目录必须用户明确授权后由有资源维护权限的用户添加，AI MCP 工具只有读取能力，不能自行扩展目录。日志文件尾读、检索、目录浏览和文本读取使用同一边界；服务名方式的 systemd/journalctl 仍遵循原服务白名单。
