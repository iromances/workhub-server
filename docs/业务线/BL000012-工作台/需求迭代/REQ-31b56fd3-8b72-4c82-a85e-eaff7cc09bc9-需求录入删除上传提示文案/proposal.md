## 1. 背景

需求录入弹窗在"需求录入"文本框与截图/附件上传区之间常驻一条 `el-alert` 提示："截图和附件会先直接入库，再异步调用 Codex CLI 识别并回填结构化字段。支持点击上传、拖拽上传和直接粘贴截图。"该文案与上传区 dropzone 内已有的操作提示重复，用户要求删除该常驻提示。

## 2. 目标与范围

1. 删除需求录入弹窗中上述 `el-alert` 提示块，弹窗其余内容与布局不变。
2. 上传与识别功能全部不变：点击选择、拖拽、粘贴截图，提交后先保存原文与附件入库，再异步调用 Codex CLI 识别并回填结构化字段（见 REQ-b6f5532c 需求录入保存与AI识别解耦）。
3. 明确不做：不修改上传交互、提交校验、FormData 契约、后端代码与接口；不改动需求清单其他页面文案。

约束：不安装依赖，不自行启动 WorkHub 应用。

## 3. 验收标准

| 编号 | 可观察的验收条件 | 核对方式 |
| --- | --- | --- |
| AC-01 | 打开需求录入弹窗，不再显示该条"会先直接入库……"提示 | 代码核对与前端构建 |
| AC-02 | 截图/附件两个上传区仍支持点击、拖拽、粘贴，文件列表与预览不受影响 | 代码核对与前端构建 |
| AC-03 | 提交链路不变：原文与附件保存入库后异步识别、失败可重试 | 代码核对（提交逻辑未改动） |
