- 明确不修改范围：其他弹框、列表页、后端。

- [ ] 条件 2：弹框体 `flex: 1; min-height: 0; overflow-y: auto`；内容超出时仅弹框体出现滚动条，标题栏与关闭按钮不随内容滚走（样式在位已核对，滚动表现未在真实页面核对）。
