# 系统预警采集持久续读验证

日期：2026-11-04。业务线：BL000012-工作台。独立分支 codex/agent-workbench-autonomy，工作树 workhub-agent-autonomy/workhub-server。沿用已确认v4，不改变Agent负责业务判断、平台负责证据约束的职责。

## 已实现

- 预警采集固定时间区间及范围/规则定义，分页位置落库。每次至多读取现有pageSize/maxEventsPerRun中较小的条数；未读完保持PARTIAL，不把最新日志时间当成完整覆盖游标。整段读取结束后才推进覆盖上界。
- 每页事件、通知、不可变来源回执和续读位置同事务提交。只捕获唯一键重复，其他入库错误使整页回滚；重扫不会重复创建事件与通知，缺少服务名/内容截断累计为证据缺项，不能被最后一页为空掩盖成SUCCESS。
- 数据库租约和版本控制每个范围的领取与提交，旧执行者不能提交或覆盖新所有者。停用或删除范围在续读队列LIMIT之前排除，不占用有效范围的名额。
- 原每分钟调度开启新轮次，新增短周期任务只续读未完成区间，不重置区间或另开新轮次。PIT正常时跨客户端实例沿原位置续读；过期/目标变化时明确重启原区间，丢弃旧sort并保留已落库去重事实，不能把旧游标套到新快照。
- 后续轮次按既有初始回溯时长重叠扫描，发现该窗口内的迟到记录。旧同步状态没有不可变分页证明，不回填为已完成采集。回执保存完整范围/规则定义及实际查询摘要、事件标识/原文摘要和分类；PIT原文只保留在内部状态。
