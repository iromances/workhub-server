## 行为与边界

- 运行级 reconciliation 接口提供原调用意图、版本/材料摘要、已有回执来源、CLI 主机/PID/启动身份和待核对项。管理者逐项填写确认未发出或已结束的依据，选择重新规划、等待补充或结束；须具备任务查看/操作与 Agent 管理权限，Agent 工具无此入口。
- 只接受失租约且仍保留原句柄的运行。CLI 与企业工具分别核对，已记录启动的 CLI 不接受“未发出”；同机存活进程及存活但身份不明的 PID 拒绝解除。父 PID 消失不作为进程树停止证明。原生执行器的 `startedAt` 映射到预览 `startInstant`，测试核对真实 Mapper 保存的值及进程探针参数。
- 实际回执及同事务保存的巡检结果优先。快照包含回执，防止其在运行版本不变时被人工覆盖。核对、旧行动处理标记、人工新输入、状态和审计同事务；同键同人同内容返回原结果。实际回执与人工提交竞争只允许一方成功，释放后旧所有者失效。
- 人工核对不生成模型/工具/CLI机器回执或测试/发布产物，不修改原回执。继续时重新规划，保留步数与耗时，并复核当前权限、Provider、范围、工具及预算。已取消或停用导致取消的运行只能结束；领域交付/发布对账独立处理。
