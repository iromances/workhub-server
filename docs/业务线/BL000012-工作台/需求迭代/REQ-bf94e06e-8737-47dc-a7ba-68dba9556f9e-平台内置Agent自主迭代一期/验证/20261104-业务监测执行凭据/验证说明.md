- XXL-JOB 实时明细固定实际监测定义、业务线/环境、日期/筛选条件、MCP 目标摘要及 readonly 配置。统计、全状态活动时间和分页明细使用同一条 SELECT，避免不同读取时点拼出错误结论；执行凭据随既有不可变 Observation 保存，无新增迁移。
- 严格校验真实 MCP 批量回执格式、批次数量、字节截断、统计必需字段、非负整数、分页数量及重复日志。缺失聚合不再默认为零失败，真实零值仍可使用。查询成功与业务出现错误分开表示，业务含义交给 Agent 判断。

- 复查使用真实日志活动时间判断新鲜度。完整查询、有发布后的新活动、满足获批观察窗口和 Agent 判断时可以通过；重复查询旧活动不增加有效样本，没有任何活动的空失败集合不能证明恢复。
