- 新增 `inspection.next/ack/pending`。系统预警、已结束账务运行、已登记缺陷按任务/来源/业务范围保存扫描位置及快照；每轮固定最大ID、每页20条，到末尾重新扫描。来源ID与内容摘要去重，低ID迟到、运行后完成、缺陷内容更新可在后续扫描中发现。
- 快照、位置和调用回执同事务；确认结论、历史和回执同事务。相同实际调用键返回已保存结果，不同参数拒绝。新调用仍返回未确认记录；不能抢占等待输入或执行结果未知的运行。原运行已明确终止且无句柄后，后续运行取得同一快照及新的本运行Observation。
- 只凭实际匹配信号可确认 `FINDING`；相同事实已在其他Observation登记时允许复用原信号。账务规则差异可附同一运行及配置的详情证据，其他运行的证据拒绝。`NO_FINDING/NEEDS_INPUT`也是AI分析记录，不证明健康、修复或发布。
- 缺陷仍没有环境字段，不造环境Observation。待补充项每页10条，显式重领取保留旧分析。长记录先脱敏；截断时保留记录ID且只能标为待补充。每次执行重新核对来源权限和任务范围。
