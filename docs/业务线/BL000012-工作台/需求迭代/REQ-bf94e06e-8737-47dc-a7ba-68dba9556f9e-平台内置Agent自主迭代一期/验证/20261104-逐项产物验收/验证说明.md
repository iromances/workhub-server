## 实现与边界

- API finishDecision 与 CLI finishSavedNative 共同调用 RunStore.finish。运行锁内读取当前清单、交付记录与同版本 CODE_DELIVERY 回执；报告、代码凭据、验收事件与状态原子提交。代码项不使用 AI 总结、计划分支名或任意产物的 kind/provenance 字符串作为交付证明。
- 有效清单必须是最新版本，工作区、策略、问题方案、BUG上下文均未变化；当前范围、代码/来源权限仍保留。每个仓库回执精确匹配提交和分支；变更仓库有已核验MR，未改动仓库核验基线。代码产物保存清单与原始回执摘要，能追溯实际来源。
- 仅代码任务可完成；要求实测、发布或业务验证时明确保留未满足。不会改变 readyForReview、问题解决状态或历史完成结论。取消优先，损坏记录及事务写入失败不会留下半份报告或伪完成。
- 只读 acceptance API 和页面复查不写产物。前端按当前运行、版本、权限和激活状态隔离异步回执；失败清理旧内容。代码证据详细内容仍走原候选/交付接口权限。
