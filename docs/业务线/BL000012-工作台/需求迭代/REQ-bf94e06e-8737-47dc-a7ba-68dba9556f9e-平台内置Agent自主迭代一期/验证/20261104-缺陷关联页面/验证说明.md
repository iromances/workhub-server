## 实现

- 问题详情和 `case.detail` SUMMARY 返回 `bugContext`：关联历史条数、不同缺陷数、最新关联中原文变化及不可用数量。后端计算全部最新关联，不从当前分页推算；重新关联后旧历史不使当前依据继续失效。
- 新增关联缺陷页签，独立分页显示缺陷原文、验收、关联依据、证据范围、最新/历史标记及来源版本。历史环境限制随原证据显示；AI 关联不代表修复或环境已确认。
- 分析方案和候选代码显示需求依据变化。权限撤销后无关联问题返回分析页；有缺陷关联的问题清除全部详情。无权限时迟到的详情也被拒绝，服务端原有权限校验保持适用。
- 修正构建检查：根 tsconfig 只有 project references，原 `vue-tsc --noEmit` 不构成全应用类型验证。`build` 现显式检查应用与 Vite 配置。首次严格检查发现 3 个未改动基线文件的 10 处诊断；修复可空响应、展示选项、时间格式化的空值、指标可选字段和测试夹具，未改变需求生命周期或实际授权。
