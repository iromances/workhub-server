### T-04：运行恢复、人工审核与修复领域流程

- 输入：Design §3.4–3.6、现有身份/项目/业务线权限、T-01–03。

- 不修改：模型不能审核自身；不复活旧 v2 的“逐条确认设计才可编码”门槛；不改变普通人工需求语义。
- 建议研发任务标题：贯通自动研发与人工发布审核。
- [ ] 通用任务和问题领域状态分离；报告/审查任务可直接交付，修复任务按目标继续推进；只在缺信息、越界或需审核时等待人。
- [ ] 运行、计划与工具步骤可恢复；补充指令可重新规划，取消/重试保留原证据，多 Agent 不串上下文。
- [ ] 审核绑定准确的任务/变更版本、manifestHash/环境/Job 绑定版本/参数；巡检修复额外绑定 caseVersion；代码或绑定改变使批准失效。
- [ ] 无权限/跨业务线换 ID/重复审核/并发领取拒绝或幂等；审核与发布请求同事务，不依赖丢失的内存回调。
- 验证计划：状态机、权限、幂等、重启、审核失效、任务预算与取消竞态测试。
