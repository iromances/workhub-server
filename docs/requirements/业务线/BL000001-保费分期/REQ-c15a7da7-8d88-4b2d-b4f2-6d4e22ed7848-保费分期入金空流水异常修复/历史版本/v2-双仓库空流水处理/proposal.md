## 背景与授权来源

生产 XXL-JOB 任务 46 `pendEntrySchedule` 在交行当日流水为零时失败。日志 2754547（2026-10-21 00:10）显示调度成功、执行空指针；银行日志显示 `0000` 成功且记录数为 0。Payment 返回成功但 data 为空，SAPS 在 `PendEntryBizImpl.java:76` 解引用。

在给出“统一无流水返回结构，并在 SAPS 增加判空”的修复方向后，用户要求“帮我打个分支改一下”。用户随后明确“不要抛异常，没有流水不保存就行了”，v2 按此要求将空响应、空 data 和空列表统一直接返回。本规格承接该最新授权；未授权生产部署、真实银行请求或数据修正。

## 范围与约束

1. Payment 明确收到零条流水时返回非空 data 和空 detailLists，保持查询成功语义。
2. SAPS 在响应为空、成功响应的 data 为空或明细列表为空时直接返回，不保存流水、不抛异常。
3. 新增隔离回归测试；正常流水保存、出金过滤、银行拒绝结果、挂账幂等逻辑保持现有口径。
4. 不改金额、账户、单据状态、调度频率、自动结算规则、数据库结构或配置；不安装软件或依赖。
