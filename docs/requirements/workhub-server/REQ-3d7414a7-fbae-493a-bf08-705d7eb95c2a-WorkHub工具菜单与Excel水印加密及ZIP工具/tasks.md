### T-02：复用 Excel 核心和实现 ZIP

输入：Demo 核心源码、现有 POI 5.4.1、Design §2/§4。输出：`service/tools/excel`、ZIP 服务及合成数据测试。

- [ ] 提取纯服务逻辑和可见水印拼接，去除 Swing 依赖，独立模式支持审批号为空且不伪造身份。
- [ ] 保留六项独立选项、默认值、打印及普通视图水印、透明对象、自定义属性和冲突保护。
- [ ] Excel Office Agile AES-256、ZIP WinZip AES-256 + Deflate，分别随机/手动密码；不降级、不覆盖源文件。
- [ ] ZIP 支持中文名和多文件，拒绝重复名；返回逐文件和最终包 SHA-256。
- [ ] 新依赖仅在 T-01 授权后下载；不安装桌面软件，不复制整个 Demo JAR。

计划验证：迁移适用的 64 组合测试、密码/格式/源保护测试；ZIP 正误密码与包头/回读哈希；源文件指纹不变。历史 Demo 测试不算本次执行结果。

### T-03：文件和异步任务基础

输入：Design §3/§4；参考已有 TaskExecutor、权限/审计模式。允许修改：tools 对应 model/dao/service/controller/job、所需配置声明和新增 Flyway 脚本；不改已有附件存储模型与原接口限额。

- [ ] 专用流式上传、server-generated 路径、大小/哈希验证和同源短期票据。
- [ ] 文件/任务/票据三表、requestId 幂等、单 worker/有界队列、明确失败与重启中断状态。
- [ ] 产物校验完成后才发布；失败清理 staging，无半成品成功链接。
- [ ] 新增工具权限、所有权/管理员范围检查；猜 ID、跨任务票据、过期票据不能读取或覆盖文件。
- [ ] 专用主密钥配置声明、密码 AES-GCM 包装、单独查看、日志白名单、到期清理。
- [ ] 运行中不清理；原始 Desktop/已有附件不在清理范围；保留文件和密码到期时间在结果可见。

计划验证：MockMvc 与服务测试，上传 20 MB 以上及边界、伪长度/伪哈希、目录穿越、重复请求参数冲突、队列满、I/O/DB 故障、重启恢复、到期任务及日志不含密码。迁移先在隔离测试数据库验证，不在当前真实数据库执行。

### T-04：MCP 和需求关联

输入：Design §3.3 与既有需求 API。输出：六个 MCP 工具、typed schema、annotations、需求关联查询。

- [ ] 经上传票据接收 AI 本地文件；无需向模型返回大文件正文、服务密钥或客户端 Bearer Token。
- [ ] 创建/轮询/下载/取密码完整调用链，按任务 token 隔离共享 MCP 身份。
- [ ] 需求绑定核对类型、ID 与附件所属，审批编号由后端读取；不触发取数、不修改需求状态。
- [ ] 更新 MCP 功能说明，保留数据库只读、脱敏与白名单约束。
- [ ] 普通 task/status 响应没有密码；独立查看密码留痕。

计划验证：工具列表/schema 快照；所有权和 token 负例；从合成文件上传到 Excel、ZIP、下载和哈希的 API 集成测试；独立模式没有审批号也可按已定义规则工作。
