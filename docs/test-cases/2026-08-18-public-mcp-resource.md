## 2. 测试范围

- 核心场景：公共数据库资源不选择业务线即可保存，MCP 返回公共标识和特征标签。
- 边界场景：公共资源忽略历史兼容业务线字段；重复特征标签去重；现有业务线资源行为不变。
- 异常场景：非公共资源缺少业务线时拒绝保存。
- 不纳入自动化测试的范围及原因：真实禅道连接需要部署迁移并由用户录入只读凭据，使用测试环境连接验证替代。

- 外部依赖：无
- 测试数据准备方式：单元测试构造公共资源和业务线资源 catalog
