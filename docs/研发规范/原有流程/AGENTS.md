# 原有流程入口

仅在用户本次任务明确选择「原有流程」后使用。先遵守[通用约束](../通用约束.md)，再按需读取[研发要求与约定](研发要求与约定.md)和[研发设计规范](研发设计规范.md)。不把 SDD 的 Proposal、Design、Tasks 当作本流程的正式审批产物。

本流程按需求在 `docs/业务线/{业务线编号}-{业务线名称}/{需求编号}-{需求名称}/` 管理 `研发方案.md` 与 `测试用例.md`；业务线与需求编号、名称和归属按[通用约束](../通用约束.md)从系统确认，不创建占位正式目录。方案依照[研发设计规范](研发设计规范.md)的结构和触发条件编写，经审核后再实施；测试计划与实际结果分开记录。旧文档引用的测试指引或模板若在当前分支不存在，不得声称已读取或凭空补出其内容；按现存规则起草并说明缺失。需求生效并核实后更新同一业务线目录的 `系统现状.md`。
