## 1. 自动化测试

| 编号 | 场景 | 预期结果 | 执行结果 |
| --- | --- | --- | --- |
| AUTH-001 | MCP Runtime 已由 MCP Token 完成认证，随后经过 JWT 过滤链 | JWT 过滤器跳过该请求，不解析 MCP Token，`workhub-mcp/ROLE_MCP` 认证保持不变 | 通过 |
