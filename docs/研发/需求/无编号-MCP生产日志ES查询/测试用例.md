# MCP 生产日志 ES 查询测试用例

## 1. 自动化覆盖计划

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| ELK-MCP-001 | MCP 工具列表 | 包含 `search_business_logs`，描述明确生产日志 ES 首选 |
| ELK-MCP-002 | 按业务线名称查询 | 解析为标准业务线编码并使用对应启用范围 |
| ELK-MCP-003 | 按业务线编码查询 | 使用同一范围，不暴露 ES 连接信息 |
| ELK-MCP-004 | 未配置或未启用关注范围 | 明确失败，不回退全局索引 |
| ELK-MCP-005 | `ALL` 模式不传服务 | 不生成服务过滤，查询范围内全部服务 |
| ELK-MCP-006 | `SELECTED` 模式不传服务 | 自动使用全部启用服务生成 `terms` 过滤 |
| ELK-MCP-007 | 指定合法服务 | 只查询指定服务 |
| ELK-MCP-008 | 指定越权服务 | 参数校验失败，不调用 ES |
| ELK-MCP-009 | 默认级别和时间 | 使用 `ERROR,WARN` 和最近 15 分钟 |
| ELK-MCP-010 | 查询 `INFO` 日志 | 固定级别过滤并允许最长 24 小时 |
| ELK-MCP-011 | `INFO/DEBUG` 超过 24 小时 | 拒绝查询 |
| ELK-MCP-012 | 仅 `WARN/ERROR` 超过 7 天 | 拒绝查询 |
| ELK-MCP-013 | 非法级别、时间倒置或未来时间 | 拒绝查询 |
| ELK-MCP-014 | 消息短语 | 生成 `match_phrase`，不接受正则或 Query DSL |
| ELK-MCP-015 | Trace ID / 请求 ID | 只使用配置字段精确过滤；字段未配置时明确失败 |
| ELK-MCP-016 | limit 边界 | 默认 50，允许 1-100，超限拒绝 |
| ELK-MCP-017 | 正常 ES 响应 | 返回结构化日志并按时间倒序 |
| ELK-MCP-018 | 多页或超限响应 | 达到 limit 停止并标记 `truncated` |
| ELK-MCP-019 | 敏感日志正文 | 手机号、证件号、邮箱、账号、IP、Token/Secret 脱敏 |
| ELK-MCP-020 | 长消息和堆栈 | 按固定上限截断，不突破总响应边界 |
| ELK-MCP-021 | ES 401/403 | 返回认证或授权失败，不包含凭据 |
| ELK-MCP-022 | ES 5xx、超时或非法 JSON | 返回归一化异常，不回显原始响应体 |
| ELK-MCP-023 | MCP 审计成功 | 记录范围、级别、数量、耗时，不记录查询原文和日志正文 |
| ELK-MCP-024 | MCP 审计失败 | 记录失败类型，不记录凭据和 ES 响应 |
| ELK-MCP-025 | 现有 ERROR 定时采集回归 | 原有采集、过滤、落库和通知测试保持通过 |

## 2. 计划执行命令

```bash
mvn -q -pl workhub-service,workhub-controller,workhub-mcp-server -am test
mvn -q -DskipTests compile
git diff --check
```

不自行启动 WorkHub，不连接未明确授权的真实 ES，不执行数据库或 ES 写入。

## 3. 手工验证计划

- 使用 MCP `tools/list` 确认新工具、参数和首选顺序说明。
- 在本地模拟 ES 响应下调用 `tools/call`，核对结构、脱敏和错误信息。
- 真实环境烟测需要用户明确指定业务线、环境和时间窗口；首个建议场景为：

```text
业务线：BL000001（保费分期）
环境：prod
服务：scf-payment
级别：INFO
短语：查询交易明细返回记录条数
时间：告警前后 15 分钟
```

- 真实烟测只读，不显示银行完整账号、客户信息、Token 或原始认证信息。
