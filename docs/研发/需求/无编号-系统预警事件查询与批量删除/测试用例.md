# 系统预警事件查询与批量删除测试用例

## 1. 自动化覆盖计划

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| SA-EVENT-001 | 查询传入首尾空格的消息关键词 | 去除空格后传入总数、汇总和明细查询 |
| SA-EVENT-002 | 查询关键词超过 200 字 | 返回参数错误 |
| SA-EVENT-003 | 批量删除包含重复 ID | 去重后删除，返回实际数量并写审计 |
| SA-EVENT-004 | 批量删除超过 100 个 ID | 不限制条数，正常提交全部 ID |
| SA-EVENT-005 | 控制器批量删除 | 返回事件和通知删除数量，传递当前用户和 IP |
| SA-EVENT-006 | 前端消息查询 | 请求携带 `messageKeyword` 并回到第一页 |
| SA-EVENT-007 | 当前页单选和全选 | 删除按钮显示正确选中数量，分页支持 500、1000 |
| SA-EVENT-008 | 取消删除确认 | 不调用删除接口 |
| SA-EVENT-009 | 删除当前页全部记录 | 非第一页时回到上一页并刷新 |
| SA-EVENT-010 | 无删除权限 | 不显示选择列和删除按钮 |
| SA-EVENT-011 | 删除有关联源事件 ID 的事件 | 先精确删除关联 `ELK_ERROR` 通知，再删除事件并写审计 |
| SA-EVENT-012 | 删除没有源事件 ID 的事件 | 仅删除事件，不按消息文案宽泛删除通知 |
| SA-EVENT-013 | 批量删除 200 个事件 | 先精确定位通知主键，再分别按主键批量删除通知和事件，不执行后缀函数联表删除 |
| SA-EVENT-014 | 同一源事件 ID 出现在不同业务线或环境 | 仅删除业务线、环境和源事件 ID 同时匹配的 `ELK_ERROR` 通知 |
| SA-EVENT-015 | 筛选表单按 Enter | 系统异常/慢 SQL、关注业务线和过滤规则均走与“查询”按钮相同的提交逻辑；事件查询回到第一页 |
| SA-EVENT-016 | 删除按钮与确认弹框文案 | 按钮固定显示“删除”，选中数量只在二次确认弹框中显示 |
| SA-EVENT-017 | 后端批量删除失败 | 恢复提交前选中 ID 和表格勾选，删除按钮结束加载并可重试 |
| SA-EVENT-018 | 首次进入系统预警页面 | 只加载业务线下拉选项，不自动调用预警看板、关注范围或过滤规则查询 |

## 2. 计划执行命令

```bash
mvn -q -pl workhub-service,workhub-controller -am -Dtest=SystemAlertServiceTest,SystemAlertControllerTest -Dsurefire.failIfNoSpecifiedTests=false test
mvn -q -DskipTests compile
./node_modules/.bin/vue-tsc --noEmit
npm run build
```

前端命令在同级 `workhub-web` 仓库执行。不连接生产数据库，不启动或重启应用。

## 3. 手工验证计划

- 系统异常页输入错误消息片段，核对总数、汇总和明细。
- 勾选单条、多条及表头全选，核对按钮数量。
- 取消删除确认，确认数据不变。
- 确认删除，核对当前页、总数、汇总和系统操作日志。
- 切换慢 SQL、分页、每页条数和权限账号，核对选择状态与按钮显示。
