# 保费分期——新增【代收代付报表】模块

# 一、背景

财务每月对账需要核对向不同渠道代收代付款项总额、按科目划分款项金额、按还款方式（线上还款or线下还款）划分款项金额核对系统中数据与线上、线下实际收款、付款资金一致性。

目前缺少能直观导出上述代收代付信息的模块，经与需求方沟通后决定新增【代收代付报表】模块。

# 二、需求内容

保费分期后台系统【报表管理】一级模块下新增二级模板【代收代付报表】

## 2.1【代收代付报表】页面

### 2.1.1筛选项

| 筛选项 | 组件类型 | 枚举/说明 |
| :----------------- | ----------------------------- | ------------------------------------ |
| 合作方编号 | 输入文本框，准确输入 | |
| 还款流水号 | 输入文本框，准确输入 | |
