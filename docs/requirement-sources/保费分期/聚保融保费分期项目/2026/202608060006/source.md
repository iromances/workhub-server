# 保费分期优化需求——新增接口：备付金余额查询、备付金明细查询

## 需求背景

聚保融（API模式对接的渠道）准备使用备付金账户，用于提前充值备付金账户，订单首笔款缴费单自动交易备付金账户余额，余额≥首笔款缴费单应付款金额时，系统自动划扣备付金账户余额支付缴费单，以使进件流程可快速流转。

渠道需要接口对接方式供其查询备付金账户余额情况、备付金账户交易记录情况。

因此需新增两个查询接口。

## 需求内容

### 1.新增两个查询接口：

1. 备付金余额查询
2. 备付金明细查询

均为渠道方主动调用查询。

### 2.接口字段

1. 备付金余额查询接口：
 - 建议必传入参字段：账户编号。（例：聚保融目前备付金账户编号：HZF000166_BFJZH33）
 - 返回字段：对应账户账户名称、实时余额金额、账户状态
 - 其余技术层面所需字段，请技术评估添加。
2. 备付金余额查询接口：
 - 接口用途场景：渠道推送账户编号以及时间范围，查询指定账户特定时间范围内入账（渠道充值备付金账户）、出账（系统划扣备付金账户余额结算缴费单）的明细记录
 - 建议必传入参字段：账户编号、查询起始时间、查询终止时间
 - 返回字段：交易流水号、交易金额、交易类型、交易时间、交易状态、关联业务编号（入账的记录关联【收款管理】中充值的交易流水号、出账的记录关联首笔款缴费单编号）
 - 其余技术层面所需字段，请技术评估添加。

**注：请技术评估系统承载能力，决定是否对查询时间范围宽度进行限制，或采取其他约束条件。**
