# 保费分期优化需求——接口改动：对原聚保融接口【备付金余额查询】改动以实现聚保融可通过该接口查询先行通供应链放款账户（交行户）余额

## 需求背景

经业务端沟通，聚保融需要知悉先行通供应链公司向保司放款账户余额情况，需要以接口方式提供查询。

之前需求已新增【备付金余额查询】接口供聚保融查询其备付金账单余额，综上需求，拟对该接口进行改动，以实现通过该接口可实现聚保融备付金账单以及先行通放款账户的余额查询。

## 需求内容

### 1.接口更名：

原接口“备付金余额查询”更名为“账户余额查询”

### 2.新增枚举值：

接口中"accountType账户类型“新增枚举值“2=放款户”

聚保融推送该枚举值时，即反馈先行通供应链公司交行放款账户最新余额值。

其余响应参数：

- 账户类型：2=放款户
- 账户名称：先行通供应链科技（天津）有限公司
- 账户余额：先行通供应链公司交行放款账户最新余额值
- 是否启用：true

"accountType账户类型“传值“1=备付金”时，按原逻辑，返回聚保融的备付金账户余额。
