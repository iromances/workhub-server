1、需求描述
1.1、需求背景
目前系统采用单笔实时放款模式，即业务系统在收到合作方放款申请并核验通过后，实时向第三方支付公司发起付款指令。然而，受当前保理公司出款通道受限的影响，原有实时出款链路已无法支撑当前业务，平台亟需将出款模式切换至线下订单支付模式。
1.2、 实现方案
出款模式重构：将原第三方支付机构“逐笔实时出款”模式，调整为基于订单支付的“按日汇总出款”模式。

支付执行与闭环：嘉泰财务根据支付订单，走内部请款流程，付款成功后，对支付订单进行核销。

2、需求详细
2.1、订单支付流程
2.1.1、 放款申请流程调整
1、合作方正常调用放款申请。
2、先行通资产平台接收到放款申请后，正常走风控审批，审批通过的放款单停留在“待放款”状态。
3、系统按合作方维度自动汇总前一日00:00至24:00期间的“待放款”状态放款单，生成支付订单；生成支付订单后，将对应的放款单状态改成“放款中”；“放款中”的放款单，合作方不允许撤销。
4、先行通资产平台将支付订单推送到嘉泰资产平台。
5、嘉泰根据支付订单，走内部请款流程。
6、支付订单嘉泰线下付款成功后，在系统对支付订单进行核销，核销成功后，将支付订单状态修改为支付成功，并将结果同步到先行通资产平台。
7、先行通资产平台接收到核销结果通知后，将支付订单修改为支付成功，并将对应的放款单状态改为“放款成功”。
8、“放款成功”的放款单自动走后续的出账流程，并将放款结果同步到嘉泰资产平台。
