# 公司项目原始资料

原始导入材料统一存放于本仓库 `docs/company/raw/`，保留原文、来源、版本与历史时点。具体需求材料仍在 `docs/requirement-sources/`，避免重复。

- `projects/`：按项目保存的接口原文与原始来源。
- `imports/`：其他外部导入材料。
- 来源登记在 [当前资料总览](../sources/当前仓库总览.md)，提炼后的稳定文档进入 [公司项目资料](../README.md)。

接口原文和来源记录不因迁移改写，其中旧路径表示原归档位置，按 [迁移清单](../../migrations/2026-10-30-company.json) 定位。
