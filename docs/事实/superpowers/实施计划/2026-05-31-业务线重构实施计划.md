# 业务线重构实施计划

> **给 AI 执行者：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐步执行本计划。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 将 GitLab 绑定的分组概念从“项目分组”迁移为“业务线”，并移除项目表中重复的业务线字段。

**架构：** `pm_project_group` 调整为 `pm_business_line`；`group_name` 调整为 `business_line_name`；`gitlab_group_name` 继续作为 GitLab 命名空间，同时承担业务线编码来源。项目只保留一个 `business_line` 引用。既有项目分组 API 和模型改名为业务线 API 和模型。

**技术栈：** Java 25、Spring Boot 4、MyBatis 注解、MySQL schema SQL、JUnit/Maven 编译验证。
