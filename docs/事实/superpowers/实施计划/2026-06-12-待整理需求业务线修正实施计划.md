# 待整理需求业务线修正实施计划

> **给 AI 执行者：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐步执行本计划。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 为历史待整理需求的业务线修正新增一个明确且可审计的动作。

**架构：** 后端暴露一个新的显式待整理动作接口，通过 `pm_business_line` 校验目标业务线，只更新 `structured_data_json.businessLine` 和 `projectHint`，并记录待整理历史。前端在既有待整理详情弹窗中增加一个小型编辑弹窗，保存后刷新当前详情和列表数据。

**技术栈：** Java 25、Spring Boot 4、MyBatis 注解 mapper、JUnit 5、Mockito、Vue 3、TypeScript、Element Plus。
