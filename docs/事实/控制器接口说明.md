# WorkHub Controller 接口说明

本文档按 controller 层梳理当前暴露给前端、外部系统和 AI/MCP runtime 的 HTTP 接口。接口表统一包含 `系统路径`，用于标注前端功能入口或调用来源；非前端页面直接触发的接口标为 `后台/系统调用`、`外部回调` 或 `通用附件`。

## 1. 通用说明

| 项目 | 说明 |
|---|---|
| 基础路径 | 业务接口统一以 `/api` 开头。 |
| 鉴权 | 除登录、健康检查和企业微信回调等明确匿名接口外，默认需要登录态或 JWT。 |
| 权限 | 菜单查看使用 `*:view` 权限；新增、编辑、删除、启停、重置、授权等按钮动作使用细粒度 `*:create/*:update/*:delete/*:status/*:assign-*` 权限；历史 `*:manage` 权限作为兼容权限仍可通过后端校验。 |
| 返回格式 | 以项目统一响应结构返回；分页接口通常返回 `items/total/page/pageSize`。 |
| 敏感字段 | 系统配置、支付凭据、AI Provider API Key、MCP 资源密码和 GitLab Token 不回显明文，只返回脱敏值或是否已配置。 |
| 系统路径 | 采用 `一级菜单-页面/弹窗-动作` 格式；多个入口用顿号分隔。 |
| 文档维护 | 新增、移除或改变接口语义时，同步更新本文档。 |

## 2. 认证接口

控制器：`AuthController`

| 方法 | 路径 | 系统路径 | 用途 | 请求/参数 | 关键说明 |
|---|---|---|---|---|---|
| `POST` | `/api/auth/login` | 登录页-登录 | 用户名密码登录 | 请求体：`LoginRequest` | 返回 JWT 和当前用户信息。 |
| `GET` | `/api/auth/me` | 全局-恢复登录态 | 获取当前登录用户资料 | 需要 JWT | 用于前端恢复登录态、角色和权限点。 |
| `PUT` | `/api/auth/me` | 顶部导航-个人信息 | 修改当前登录用户昵称 | 请求体：`UpdateProfileRequest` | 仅允许当前用户修改本人昵称；返回最新用户资料。 |
| `POST` | `/api/auth/change-password` | 顶部导航-修改密码 | 当前用户修改本人密码 | 请求体：`ChangePasswordRequest` | 校验旧密码；新密码至少 8 位。 |

### 11.3 需求阶段动作接口

| 方法 | 路径 | 系统路径 | 用途 | 请求/参数 | 关键说明 |
|---|---|---|---|---|---|
| `POST` | `/api/intake/{id}/stage-actions` | 需求管理-查看详情-阶段动作 | 按需求业务阶段执行显式动作 | 默认 `application/json`，请求体 `IntakeStageActionRequest`；上传阶段产出文件时支持 `multipart/form-data` 和文件字段 `dataFiles` | 推进需求状态并记录历史；具体动作见下表。 |

| 动作编码 | 适用场景 | 状态变化 | 关键字段/规则 |
|---|---|---|---|
| `START_CLARIFICATION` | 开始澄清 | `已收录` -> `待澄清` | 研发需求可传 `aiClarificationEnabled` 控制是否启用 AI 辅助澄清。 |

| `CONFIRM_CLARIFICATION` | 澄清完成 | 研发：`待澄清` -> `待评估`；数据提取/运维：`待澄清` -> `待处理` | 不强制校验 AI 澄清分析状态；研发需求完成后自动触发 AI 任务评估。 |

| `COMPLETE_EVALUATION` | 历史兼容动作 | 不再支持手工推进研发评估 | 研发需求必须通过 `/development-analysis/confirm` 进入 `待排期`。 |
| `CONFIRM_SCHEDULING` | 排期确认 | `待排期` -> `待设计` | 可填写预估开发、提测、上线日期并写入结构化数据。 |
| `CONFIRM_DESIGN` | 设计确认/研发开始 | `待设计` -> `开发中` | 记录研发开始日期。 |
| `SUBMIT_TESTING` | 提交测试 | `开发中` -> `测试中` | 录入实际开发工时、实际开发完成日期和实际提测日期。 |
| `PASS_TESTING` | 测试通过 | `测试中` -> `待验收` | 录入预约验收日期、实际测试工时和实际测试完成日期。 |
| `CONFIRM_ACCEPTANCE` | 验收确认 | `待验收` -> `待上线` | 记录实际验收日期。 |
| `CONFIRM_RELEASE` | 上线确认 | `待上线` -> `已完成` | 记录实际上线日期。 |
| `CLOSE_REQUIREMENT` | 关闭需求 | 未到 `已完成/终止关闭` 的需求 -> `终止关闭` | 必须填写 `closeReason`，可填写 `occurredAt` 作为关闭日期。 |

| `POST` | `/api/payment/merchants/{merchantId}/params` | 支付配置-支付商户-商户参数-新增或覆盖 | 新增或覆盖文本商户参数 | 请求体：`PaymentMerchantParamSaveRequest` | 按参数键新增或覆盖；编辑时 `paramValue` 留空表示保留旧值。 |
| `PUT` | `/api/payment/merchants/{merchantId}/params/{paramId}` | 支付配置-支付商户-商户参数-编辑 | 更新指定文本商户参数 | 请求体：`PaymentMerchantParamSaveRequest` | 更新指定参数。 |
| `POST` | `/api/payment/merchants/{merchantId}/params/file` | 支付配置-支付商户-商户参数文件-新增或覆盖 | 上传文件新增或覆盖商户参数 | `multipart/form-data`；字段：`paramKey`、`valueType`、`fileValueType`、`file`、`remark` | 文件内容按 `fileValueType` 保存为文本或二进制 Base64。 |
| `PUT` | `/api/payment/merchants/{merchantId}/params/{paramId}/file` | 支付配置-支付商户-商户参数文件-编辑 | 更新文件型商户参数 | `multipart/form-data`；字段同新增，`file` 可为空 | 文件为空时只更新元数据，不替换原文件内容。 |
| `GET` | `/api/payment/merchants/{merchantId}/params/{paramId}/file` | 支付配置-支付商户-商户参数文件下载 | 下载文件型商户参数 | 路径参数：`merchantId`、`paramId` | 仅文件上传来源的参数可下载。 |
| `GET` | `/api/payment/merchants/{merchantId}/secrets` | 支付配置-支付商户-兼容秘钥 | 查询商户秘钥兼容列表 | 路径参数：`merchantId` | 页面不再新增秘钥；历史秘钥已迁移到商户参数。 |
| `GET` | `/api/payment/bindings` | 支付配置-支付商户-项目用途绑定 | 查询业务支付绑定列表 | 查询参数：`projectId`、`businessLine`、`merchantId`、`purposeCode`、`status` | `businessLine` 优先传业务线编码，兼容名称；商户详情绑定区块按 `merchantId` 调用；`projectId` 为空表示业务线通用绑定。 |
| `POST` | `/api/payment/bindings` | 支付配置-支付商户-新增绑定 | 新建业务支付绑定 | 请求体：`PaymentProjectBindingSaveRequest` | 从编辑商户弹窗发起时固定传当前商户 `merchantId`；业务线按编码保存并展示主数据名称；支持多用途和关联商户。 |
| `PUT` | `/api/payment/bindings/{id}` | 支付配置-支付商户-项目用途绑定-编辑 | 更新业务支付绑定 | 请求体：`PaymentProjectBindingSaveRequest` | 规则同新增。 |
| `GET` | `/api/payment/projects/{projectId}/bindings/resolve` | 后台/支付绑定解析 | 解析项目用途应使用的生效商户绑定 | 查询参数：`purposeCode` | 优先项目专属绑定，找不到时按项目所属业务线编码回退通用绑定。 |
| `GET` | `/api/payment/purposes` | 支付配置-用途下拉 | 查询系统内置支付用途字典 | 无 | 返回 `BIND_CARD/WITHHOLD/REFUND/TRANSFER/WITHHOLD_SPLIT_SETTLEMENT` 等用途和历史用途映射。 |
